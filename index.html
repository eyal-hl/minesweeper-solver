Detection legend — what each overlay means

Unrevealed cells (probability overlays)

Green / ✓ — certain safe (0% mine)
Amber / % — uncertain, shows probability
Red / ✕ — certain mine (100%)
? — no constraint info (isolated cell)

Detected cell types (debug outlines)

Blue outline — number cell
Detected by: classic minesweeper → color match (blue=1, green=2, red=3…); modern style → Otsu threshold + shape heuristics (bounding box ratio, crossing count)
Orange outline — flag
Detected by: red pixel density > 3% of cell area
Lime outline — empty revealed cell
Detected by: low brightness variance (StdDev < 12) with no visible glyph
No outline — unrevealed
Detected by: high pixel variance (3D bevel highlight/shadow pattern) or fallback

Grid detection method

The grid is found by computing the average brightness of every column (and row) of pixels, then autocorrelating the brightness profile to find the dominant repeating period — the cell size. Grid lines appear as periodic minima (darker than cell interiors). No external libraries used.
